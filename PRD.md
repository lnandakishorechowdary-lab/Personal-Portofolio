# Portfolio Website PRD

## Purpose

Create a modern, responsive personal portfolio website that presents my
projects, skills, education, achievements, certifications and contact
information clearly.

## Audience

Recruiters, internship reviewers, teachers and people interested in my work.

## Main Goals

- Explain who I am quickly.
- Show my strongest projects.
- Make my skills easy to understand.
- Present my education clearly.
- Show achievements and certifications.
- Provide a clear contact action.
- Make the website responsive on mobile, tablet and desktop.

## Required Sections

- Hero
- About
- Skills
- Projects
- Education
- Certifications
- Achievements
- Resume
- Contact
- Footer

## Required Behaviour

- Navigation links should work.
- Navigation should scroll to the correct section.
- Project links should work.
- Buttons should work.
- Mobile navigation should work.
- Website should work on desktop, tablet and mobile.
- No unwanted horizontal scrolling.
- Text should remain readable on small screens.

## Technology

- React
- JavaScript
- HTML
- CSS
- Vite

## Important

Use only real information provided in the project.
Do not invent achievements, clients, testimonials, awards or results.
