# Personal Portfolio - Lavu Nandakishore Chowdary

Modern, responsive personal portfolio website showcasing projects, technical skills, academic background, and direct contact integration.

## 🚀 Built With

- **React 18** - Interactive component architecture
- **Vite** - High-performance frontend build tooling & dev server
- **Vanilla CSS** - Tailored glassmorphism and modern dark cinematic aesthetic
- **EmailJS** - Client-side contact form dispatch with validation
- **Lucide Icons** - Clean, modern SVG icons
- **TypeScript Support** - Integrated tsconfig and typed component support

## 📋 Features

- **Hero Section**: Personal branding, student profile showcase card with profile DP, online status indicator, and dynamic CTA buttons.
- **Ambient Visual Effects**: Interactive background styling with glassmorphism cards and smooth responsive layout.
- **About Me**: Academic background at GIET University (CSE-AIML, Batch 2025-2029) and core technical focus areas.
- **Skills Showcase**: Categorized technical skills across Core CS, Web Technologies, and Machine Learning.
- **Projects**: Fact-based project showcases with tech tags and links.
- **Contact Form**: Real-time form validation, accessible labels, loading states, and direct email delivery to `lnandakishorechowdary@gmail.com`.

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16+ recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lnandakishorechowdary-lab/Personal-Portofolio.git
   cd Personal-Portofolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables for the contact form:
   - Copy `.env.example` to `.env`:
     ```bash
     cp .env.example .env
     ```
   - Add your [EmailJS](https://www.emailjs.com/) credentials:
     ```env
     VITE_EMAILJS_SERVICE_ID=your_service_id
     VITE_EMAILJS_TEMPLATE_ID=your_template_id
     VITE_EMAILJS_PUBLIC_KEY=your_public_key
     ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
